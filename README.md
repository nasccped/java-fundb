# java-fundb

A tiny database repl that I've made for fun.

## Requirements

This java program was built on top of these tools:
- `jdk 21.0.11`
- `make` cmd

Using a lower version can also works, btw.

You'll also need `git` to clone the project!

## Set up

1. clone the repository:
```sh
git clone https://github.com/nasccped/java-fundb && cd java-fundb
```

2. use the `Makefile` as build tool:
- `make build`
- `make run`
- `make clean`
